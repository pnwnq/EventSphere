# 想和她一起玩 (EventSphere)

想和她一起玩是一款充满海洋和天空风情的小型社交活动平台，旨在让朋友之间更轻松愉快地组织和参与聚会活动。通过无处不在的骰子元素、海洋和天空主题的游戏化界面和基础增强现实技术，我们让整个使用过程变得有趣而简单。

## 主要特点

- **海洋和天空主题UI设计**：以可爱的小鲸鱼和飞鸟为吉祥物，打造沉浸式的海天世界体验
- **无处不在的骰子元素**：从用户注册到活动创建，处处可见骰子，增添随机性和乐趣
- **悬浮骰子框**：用户打开app即可看到悬浮的骰子框，随时可用
- **简单小游戏**：各种小游戏，适合聚会时娱乐，丰富聚会时光
- **简化的社交活动组织流程**：轻松创建和加入活动，告别繁琐的规划过程
- **基础增强现实（AR）功能**：通过简单的AR互动游戏，将海洋和天空元素带入现实世界
- **用户颜色标识系统**：每个用户都有独特的颜色标识，方便识别
- **事件投票功能**：用户可以对感兴趣的事件进行投票，促进群体决策
- **智能群组加入机制**：基于时间范围和数字代号，轻松加入群组

## 应用场景

- 朋友聚会：快速组织和决定聚会细节，享受骰子带来的随机乐趣
- 日常娱乐：享受简单有趣的小游戏
- 群体决策：通过事件投票功能，轻松达成共识

## 技术栈

- **前端**：Flutter, Dart
- **后端**：Firebase (考虑中) 或简单的自建服务器
- **增强现实**：ARCore (Android), ARKit (iOS)

## 开始使用

1. 克隆仓库：`git clone https://github.com/pnwnq/EventSphere.git`
2. 安装依赖：`flutter pub get`
3. 配置AR开发环境：
   - Android: 设置 ARCore
   - iOS: 配置 ARKit
4. 运行应用：`flutter run`

## 功能预览

- **用户注册**：用户可以自行输入用户名，或使用骰子随机生成有趣的用户名
- **活动创建**：通过骰子决定活动时间、地点和主题，让策划过程充满惊喜
- **群组管理**：轻松创建和加入群组，组织小圈子海天主题活动
- **AR互动游戏**：将虚拟海洋和天空元素带入现实世界，增添社交乐趣
- **事件投票**：用户可以对感兴趣的事件进行投票，当所有人都投票时，事件变为蓝色
- **智能群组加入**：在特定时间范围内输入相同的数字代号即可加入群组
